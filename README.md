Тема: Разведочный анализ данных (EDA) бразильского маркетплейса Olist

Контекст: Olist — крупнейшая платформа электронной коммерции в Бразилии, объединяющая тысячи независимых продавцов.

Аналитические задачи
1. Общий анализ продаж:
- Общая выручка
- География продаж
- Динамика выручки (GMV) по месяцам
- Средний чек (AOV)

2. Анализ отзывов:
- Распределение оценок (1–5)
- Корреляция оценок с ценой

3. Анализ продавцов:
- Средний чек
- Количество продаж
